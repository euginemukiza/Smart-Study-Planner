# Smart Study Planner

The Smart Study Planner is a simple Python program that helps students record, view, search and analyse their study sessions.

## Features

* Add a study session
* View all sessions
* Search sessions by subject
* View study statistics
* Save and load study records

## Classification

* Below 30 minutes = Short
* 30 to 90 minutes = Medium
* Above 90 minutes = Long

## How to Run

Run the program using:

`python smart_study_planner.py`

## Files

* `smart_study_planner.py` - Main Python program
* `study_log.txt` - Stores study session records
* `README.md` - Project information
